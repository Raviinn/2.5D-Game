# AI Prompt: Formatted GDD

Paste the prompt below into an AI, then paste the contents of `Game_Design_Document.md` where it says `<<PASTE GDD HERE>>`.

```text
You are a professional game designer and technical writer.

Using ONLY the information in the Game Design Document below, create a complete, fully formatted,
professional Game Design Document (GDD) that is ready to paste into Google Docs.

Requirements:
- Include ALL information from the source. Do not leave anything out, summarize it away, or invent new
  design decisions. Where the source marks something as TBD or open, keep it marked as open.
- Organize it like a professional GDD: a title page (game title, subtitle "Game Design Document",
  version, date, author, elevator pitch), a table of contents, then clearly numbered chapters and sections.
- Use proper heading levels, well-structured tables, bullet lists, and short, clear paragraphs.
- Rewrite rough notes into clean, polished prose where it helps readability, but keep all numbers,
  names, values and decisions exactly as given.
- Keep the status markers (✅ decided/built, 🟡 draft/prototype, ⬜ open) and include a legend.
- Gather every open question into a dedicated "Open Questions" chapter near the end.
- Keep a consistent tone and formatting throughout.

Source Game Design Document:
<<PASTE GDD HERE>>
```
