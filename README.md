# Beast — 2.5D Fantasy Action RPG

A 2.5D medieval fantasy action RPG made in **Unity 6 (6000.0.34f1)** with URP. You play pixel-art sprite characters in a 3D world. You fight, farm a field the Blight can't touch, trade, take quests and build standing with the Free Hollows. Solo, part-time project for Steam/PC.

## Opening the project
1. **Unity Hub → Add → Add project from disk** → choose this folder.
2. Open it with **Unity 6000.0.34f1**. The first open imports everything, which takes a few minutes.
3. Press Play in **Assets/_Project/Scenes/Bootstrap** to see the title screen. Press Play in **World_Test** to skip straight into the world (slot 1).

All placeholder art (sprites, environment textures, crops) is generated by the setup menus under **Beast → Setup**. Each one is safe to re-run.

## Layout
| Folder | What's there |
|---|---|
| `Assets/_Project/Scripts/Core` | Boot, services, save/load (3 slots), settings, input, game state, world clock |
| `Assets/_Project/Scripts/Gameplay` | Combat, enemies & AI, items, farming, economy, progression, quests & dialogue, reputation, climbing, day/night & weather, UI |
| `Assets/_Project/Scripts/Editor` | The **Beast → Setup** menus that build the scenes, data and placeholder art |
| `Assets/_Project/Dialogue` | Ink conversations (Oswin, Brenna) |
| `Assets/_Project/Data` | Items, enemies, quests, shops, skills… (ScriptableObjects) |
| `Docs/` | Game Design Document, full test checklist, QA reports and the automated test scripts |
